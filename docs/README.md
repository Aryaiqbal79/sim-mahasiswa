# docs/

Direktori ini berisi dokumentasi tambahan dan screenshot untuk proyek SIM Mahasiswa.

## Isi

- `screenshot_menu.png` — Screenshot tampilan menu utama
- `screenshot_tambah.png` — Screenshot form tambah mahasiswa
- `screenshot_tabel.png` — Screenshot tabel daftar mahasiswa
- `screenshot_test.png` — Screenshot hasil pytest

## Menambah Screenshot

Jalankan program, lakukan operasi, kemudian ambil screenshot dan simpan di sini.
Referensikan screenshot di README.md menggunakan:

```markdown
![Menu Utama](docs/screenshot_menu.png)
```
